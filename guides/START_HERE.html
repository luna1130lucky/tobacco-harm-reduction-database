发布与维护

这是一个 GitHub Pages 静态网站。数据保存在 data 文件夹的六张 CSV 表中。

首次开启 GitHub Pages

  1. 打开仓库 Pages 设置。
  2. 在 Build and deployment → Source 选择 Deploy from a branch。
  3. 选择 main 和 /(root)，点击 Save。
  4. 等待 Actions 完成后访问 网站地址。

更新数据

  1. 从网站数据维护页或 GitHub data 文件夹下载目标 CSV。
  2. 用 Excel 编辑，保留英文表头和唯一 ID。
  3. 选择“另存为 → CSV UTF-8（逗号分隔）”。
  4. 上传 GitHub data 文件夹覆盖同名文件，填写提交说明。

数据口径

产品按型号、口味、尼古丁含量和市场版本区分。PMTA 上市授权、MRTP 减害声明、实际市场上市和价格记录分别保存。价格必须注明国家、城市或线上官网、商家、包装、币种、日期和税口径。空白是待采集，不表示被拒或未上市。

FDA 早期 MGO 页面已于 2024-03-28 停止更新；新状态请复核 FDA Searchable Tobacco Products Database。网站不会自动同步 FDA 或自动采价。
