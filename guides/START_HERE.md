# 发布与维护

1. 打开仓库的 [Pages 设置](https://github.com/luna1130lucky/tobacco-harm-reduction-database/settings/pages)。
2. 在 **Build and deployment → Source** 选择 **Deploy from a branch**。
3. 选择 **main** 和 **/(root)**，点击 **Save**。
4. 等待 Actions 完成，网站地址为 `https://luna1130lucky.github.io/tobacco-harm-reduction-database/`。

更新资料时，下载 data 文件夹中对应的 CSV，用 Excel 选择“CSV UTF-8（逗号分隔）”保存，再在 GitHub 中上传覆盖同名文件。保留英文表头、唯一 ID、来源链接与核验日期。价格须填写国家、城市或线上官网、商家、包装数量、币种、税口径、价格适用日期和采集日期。上市年份或月份不应补写成虚构的完整日期。

FDA 早期 MGO 页面于 2024-03-28 停止更新。新状态以 [FDA Searchable Tobacco Products Database](https://www.accessdata.fda.gov/scripts/searchtobacco/) 和当前产品清单复核。PMTA 上市授权、MRTP 减害声明和实际市场上市是三个不同字段。未收录不能编码为被拒。

产品数据库适合支持产品推出事件整理；论文中的公司年度业绩、历史所有权、DID 处理期和对照组仍需另行建立。
