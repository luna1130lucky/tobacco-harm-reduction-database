# 全球减害产品信息库

网站围绕《减害产品推出对跨国烟草公司全球经营业绩的影响研究》整理产品、市场、价格和 FDA 证据。

## 开启 GitHub Pages

打开 [仓库 Pages 设置](https://github.com/luna1130lucky/tobacco-harm-reduction-database/settings/pages)，在 **Build and deployment → Source** 选择 **Deploy from a branch**，选择 **main** 和 **/(root)**，点击 **Save**。完成后访问：

https://luna1130lucky.github.io/tobacco-harm-reduction-database/

## 页面功能

- 按 PMI、BAT、Altria、JTI、Imperial、KT&G 公司归类浏览。
- 产品、公司、PMTA、价格四个视图；产品档案包含型号、口味、尼古丁强度、市场版本和证据。
- CSV 放在 data 文件夹中，可直接下载和用 Excel 更新。
- PMTA、MRTP、市场上市和价格日期分开记录。
- 首批价格注明日本、韩国、英国的销售地点或渠道，并保留历史口径。

首批样本是研究型起始库，不是全球产品全量清单。FDA 当前清单表示可能合法销售的监管记录；实际库存、地方限制、销售状态和价格需要另行核验。未收录不等于被拒，历史 MGO 不等于当前授权。

## 论文使用

产品推出事件还需和公司年度业绩、历史所有权、样本期、处理组与对照组匹配，不能把缺失产品记录编码为 0。建议保留公告、首发、全国铺货和并购生效的独立日期。
